# 🚀 Education Hub 2.0 — O‘zbekiston uchun bepul raqamli ta’lim platformasi

Education Hub 2.0 — butun O‘zbekiston bo‘ylab maktab o‘quvchilari, talabalar va o‘qituvchilar uchun 100% bepul, zamonaviy, to‘liq ishlaydigan milliy ta’lim ekotizimi.

---

## ⚡ Vercel da 1 Daqiqada Bepul Ishga Tushirish (404 Xatosiz!)

Vercel da **404: NOT_FOUND** xatosi chiqishining 2 ta sababi bor:
1. Loyiha papkasida `index.html` yoki `package.json` fayli asosiy ildiz (root) papkada bo'lmasligi;
2. Vercel loyiha sozlamalarida **Root Directory** xato ko'rsatilganligi.

Ushbu arxivda barcha fayllar to'g'rilangan va 2 ta oson usulda Vercel ga joylashtirish mumkin:

### 🌟 1-USUL: Eng oson va tezkor (Vercel Drag & Drop / Static HTML) — Tavsiya etiladi!
1. Ushbu arxivni (`education_hub_2.0_full_source.zip`) kompyuteringizga yuklab olib, papkaga chiqaring (unzip).
2. [Vercel Dashboard](https://vercel.com/dashboard) ga kiring.
3. Yangi loyiha qo'shish sahifasida arxiv ichidagi `index.html` va `vercel.json` fayllari joylashgan papkani to'g'ridan-to'g'ri Vercel ga yuklang (yoki GitHub orqali push qiling).
4. Hech qanday murakkab buyruqlarsiz, bir zumda `https://sizning-saytingiz.vercel.app` manzilida 52 ta fan va 200 ta material bilan 100% to'liq ishlaydi!

### ⚙️ 2-USUL: Next.js 14 App Router + GitHub
Agar GitHub orqali Next.js loyiha sifatida deploy qilayotgan bo'lsangiz:
1. GitHub da yangi repozitoriya oching:
```bash
git init
git add .
git commit -m "feat: Education Hub 2.0 initial release"
git remote add origin https://github.com/USERNAME/REPO_NAME.git
git push -u origin main
```
2. Vercel da **Import Git Repository** qiling.
3. **DIQQAT (Muhim!)**: Agar repozitoriyangiz ichida papka ichma-ich joylashgan bo'lsa, Vercel sozlamalaridagi **Root Directory** bo'limida `package.json` turgan papkani tanlang (masalan `./`).
4. **Deploy** tugmasini bosing!
